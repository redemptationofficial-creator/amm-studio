# AMM Studio — сайт-портфолио

Одностраничный сайт мастерской архитектурных макетов AMM Studio (Санкт-Петербург).

## О проекте
«Мы превращаем чертежи в будущее, которое можно потрогать» — архитектурные макеты, Санкт-Петербург.

- Основатель: Михаил Матвеев, 16 лет в архитектурном макетировании.
- В портфолио: макеты для Эрмитажа, музеев «Гранд Макет Россия» и «Гранд Макет История», музея-заповедника «Дивногорье», 9-метровая панорама для Росавтодора и другие проекты.

## Разделы сайта
- **О нас** — основатель и портфолио.
- **Работы** — галерея реальных фото.
- **Экспертиза и реализм**:
  1. Абсолютный реализм — детализация от текстуры травы до аэрографии и искусственного старения.
  2. Работа по вашим материалам — чертежи, 3D-модели, эскизы, фотографии.
  3. Исключительно ручной труд — каждый элемент собирается и окрашивается вручную.
  4. Инструмент для инвестора — макет показывает будущий объект, чтобы совет директоров сказал «да» быстрее.
